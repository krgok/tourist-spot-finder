周辺スポット検索アプリ

API設定

観光・食事・子供向け・お茶・仕事など、ジャンル別のスポット情報・地図・経路表示には Google Maps / Places API / Routes API のAPIキーが必要です。 ご自身の Google Cloud Console で「Maps JavaScript API」「Places API (New)」「Routes API」を有効化したAPIキーを取得し、以下に入力してください。 ログインはアプリ運営者が用意したGoogleログイン(Supabase Auth)を利用するため、キーの入力は不要です。

ログイン中は、検索・経路・写真は安全なサーバー経由で行われるため、これらのAPIキーは不要です。 地図の表示にだけ、ブラウザ用のキー(「ウェブサイト(HTTPリファラー)」と「Maps JavaScript API」だけに制限したもの)が必要です。

APIキーの安全な使い方(必ずお読みください)
  • キーはこのブラウザの localStorage に平文で保存され、Googleへの通信(画像のURLを含む)にそのまま使われます。他人が使う端末・共有のパソコンでは入力せず、使い終わったら「削除」してください。
  • 万一このページに悪意あるスクリプトが入り込むと、キーを盗まれるおそれがあります。盗まれても被害が出ないよう、Google Cloud Console の「認証情報」でキーに制限をかけてください。
    • アプリケーションの制限:「ウェブサイト(HTTPリファラー)」に、このアプリのURL(例: https://ユーザー名.github.io/*)だけを登録
    • API の制限:Maps JavaScript API・Places API (New)・Routes API の3つだけを選択
    • Google Cloud の「割り当て(クォータ)」で1日の上限を小さく設定し、「予算とアラート」で請求額の通知を設定
  • このキーを他の用途・他のアプリと共用しないでください(このアプリ専用のキーを作成)。

検索地点
よく使う起点(ホテル・自宅など)を保存・管理

この端末の中だけに保存され、アカウントやサーバーには送られません。自宅の位置になりうるため、共有の端末では保存しないでください。

    「現在地」を使うには、ブラウザの位置情報の許可が必要です。許可したくない場合や取得できない場合は「場所を指定」で地名を入力してください。

    「場所を指定」「保存した起点」で検索したときは、「Google マップで順に回る」と「マップアプリで経路を開く」のリンクに、その場所が出発地として含まれます(自分のマップアプリで開く用です)。「共有」のリンクには出発地を含めないので、自宅やホテルの位置は共有先に伝わりません。
